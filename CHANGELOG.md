## [0.1.0] - 2026-09-16
### Features
- Standalone sprite sheet editor on moth_toolkit
- Tools menu with grid frame generator
- Detect Frames tool
- Open with a blank project on startup
- New Cell rect drawing mode and Delete key to remove the selected cell
- Dock space, main menu bar and Window menu
- Dockable Sheet window with New Cell in its toolbar
- Dockable Selected Cell window with zoom and pivot editing
- Dockable Cells window with a cell list and form
- Dockable Clips window with step timelines
- Dockable Clip Preview window
- Remove the Sprite Editor window and show the project in the title
- Multiple cell selection with a prime cell
- Edit > Pivot rules for the whole selection
- File > Export Sheet copies the sheet image and repoints the project
- File > Open Recent and remembered dialog folders
- Unsaved changes indicator and prompt
- Delete removes clip steps in Clips, pivot presets move to the Cells form
- Preview background color and transparency checkerboard
- Selected Cell previews clips, playback selects cells, Set all durations
- Disable the Cells form while a clip plays
- Draw the clip step's cell number above its thumbnail
- Keyboard shortcuts for New, Load, Save, Save As and Exit
- File > Save opens Save As for an untitled project
- Rename Tools > Grid to Grid Cells
- Rename Tools > Detect Frames to Detect Cells
- Move Preferences under the Edit menu
- Browse button on the Sheet window's image path
- + Clip and + Step add a step for each selected cell
- Thumbnails in the Cells list
- Help > About dialog
- Import Sheet is undoable
- + Step uses the last step's duration, or Set all for an empty clip
- Default layout from the preferred imgui.ini

### Bug Fixes
- Crash on exit after loading a sprite sheet
- One undo step per Cells form field edit
- Failed Load, Open Recent or Save As keeps the project path
