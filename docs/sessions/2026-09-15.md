## Needs attention

- **Nothing was checked by hand.** The checks were the Debug build with clang-tidy and the smoke launch. The smoke
  launch starts the app, lets it run and closes it. It does not click or type. Every task's `Manual verification`
  steps are still to be done.

- **Two problems found outside the tasks** are under `## Discovered` in `docs/tasks.md`:
  - The cell form's undo snapshot is shared by its six fields. An edit can lose its undo step, or a later undo step
    can include earlier changes. The Clips window uses a per-field pattern that avoids this.
  - A failed File > Load (and File > Open Recent) still sets the project path, so the title names the file that
    failed and File > Save writes to it.
- **Behaviour changes you may want to confirm:**
  - Ctrl+Z, Ctrl+Y, Delete and Esc work in every window, but not while a text field or a modal tool popup is
    active. Before, Ctrl+Z and Ctrl+Y also worked while a text field was active (T-007).
  - Window > Reset Layout also opens every window (T-007).
  - A plain click on a selected row in Cells no longer clears the selection. Esc clears it (T-002).
  - Esc cancels one thing per press: picking a cell, else New Cell drawing, else the selection (T-002).
  - A pivot rule that changes nothing adds no undo step (T-003).
  - Play on a Stop clip that has played to its end starts from the first step (T-011).
- **Existing `imgui.ini` files:** a layout saved by an earlier build keeps its dock nodes, so new windows can first
  appear floating and the removed Sprite Editor window can leave an empty dock area. Window > Reset Layout fixes
  both.
- **New settings in `moth_sprite.json`:** `Show*Window` flags, `SpriteEditorPrimeColor`, `RecentProjects`,
  `LastProjectDir` and `LastImageDir`. Older settings files still load. The project file format did not change.

## Assumptions

### T-007 Docking setup

- The dock space uses its own host window and a fixed ID, so that a missing node in `imgui.ini` means "build the
  default layout".
- Reset Layout opens every window as well as re-docking them.
- Shortcuts are off while a modal tool popup is open.

### T-008 Sheet window

- New Cell is first in the toolbar, so the zoom text does not move it.
- Closing the Sheet window ends New Cell mode.
- With no image, the window shows an Import Sheet hint.

### T-009 Selected cell window

- The cell zoom fits on first draw and after New, Load and Import, and is kept when another cell is selected.
- The cell is drawn with one zoom for both axes.

### T-010 Cell list window

- Rows use `32x32`, not `32×32`, in case the font has no `×` glyph.
- The list does not scroll to a cell selected on the sheet.

### T-011 Clip editor window

- A click on a step pauses playback on that step.
- Clicking the selected clip does not reset playback.
- Picking ends on undo, redo, New, Load, Import, and when steps or clips are moved or removed.
- Steps can be reordered only within one clip.
- The timeline follows playback only while playing and after Step.

### T-012 Clip preview window

- The animation is centred when it is smaller than the canvas.
- The zoom is kept when another clip is selected.

### T-013 Remove the old UI window

- The title uses the project file name with its extension.

### T-002 Multiple selection

- Shift+click replaces the selection with the range and keeps the prime cell.
- Box select takes cells fully inside the box.
- Ctrl+drag on empty space adds a box.
- Ctrl+A keeps the prime cell.
- A click that does not drag on a selected cell selects only that cell.
- The prime colour is a new preference, magenta by default.

### T-003 Pivot helpers

- Edit > Pivot is disabled with no selection.

### T-004 Export sheet option

- The dialog starts in the sheet's folder until an image dialog has been used (T-005).
- A different typed extension is replaced by the sheet's.
- Exporting onto the sheet file itself does nothing.

### T-005 Recent files

- A missing remembered folder falls back to the old start folder.
- Open Recent does not change the remembered folders.

### T-006 Unsaved changes indicator and prompt

- An edit in a field that is still active is not yet an unsaved change.
- If saving fails or Save As is cancelled, the prompt stays open.
- Opening the prompt closes an open Tools popup.
