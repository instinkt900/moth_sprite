## Assumptions

### T-014 Preview background color and checkerboard

- Alpha counts as 0 when the 8-bit color that ImGui draws has alpha 0.
- The top-left checker square is gray.
- The picker is the last item in Preferences, after a separator, with an alpha bar.
- In Sheet, Grid and Detect Frames the background uses the image's whole-pixel size, the same size the image is drawn
  at.
- The background is drawn only inside the visible part of each window.

### T-015 Cell form undo per field

- Each field applies its value to the cell right after it is drawn, not after the whole table.
- An edit that is typed and then changed back to its old value still adds an undo step, as in the Clips window.

### T-016 Failed Load or Save As keeps the project path

- None beyond the task. The existing log lines report failures.

### Changes after the session

- With no clip selected, Selected Cell shows the cell alone, centred when smaller than the canvas.
- During a pivot drag, Selected Cell keeps the layout from before the drag, so the cell does not move under the mouse.
- Playback selects a step's cell only when the step changes, and not during a drag on the sheet, a box select or a
  pivot drag.
- The Set all value is view state: it starts at 100 for each clip, is not saved, and is not undoable. Only the
  button applies it.
- Ctrl+S and File > Save on an untitled project open Save As, like Save in the unsaved changes prompt.
